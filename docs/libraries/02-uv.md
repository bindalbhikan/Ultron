# 2. uv — installs and a lock file

**Status**: ⏳ next.

**Why**: installs 10-100x faster than pip (CI minutes on every one of ~40 workflows), and a lock file
(`uv.lock`) so every run, the office PC and a seller's machine get the exact same versions. Today
`pyproject.toml` has only lower bounds: a new pandas / openpyxl release can change a run silently.

**Plan**
1. `uv lock` from `pyproject.toml` (extras `full`, `browser`, `workings`); commit `uv.lock`.
2. `.github/actions/setup`: `astral-sh/setup-uv` + `uv sync --frozen --extra workings` in place of pip.
3. The office PC runner and `deploy/` scripts: `uv sync` too; Termux keeps pip (pure-Python core).
4. Check: one run of every workflow kind green before the old pip path goes.
